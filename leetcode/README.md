# LeetCode 副線

主線課程教的是「怎麼把程式寫得清楚、分層、有測試」。LeetCode 練的是另一件事：拿到一個小問題，想出一個正確又夠快的做法。兩者都是工程師的基本功，所以這條副線和主線並行，當作每天的加練。

## 怎麼練

每一題都照這個順序：

1. 讀「題目」，自己想三分鐘，在紙上寫出你的想法。
2. 讀「先想一想」的引導問題。還是沒有頭緒，就讀「解法一」。
3. 播放「解法二」的動畫，改幾組輸入重新執行，看懂它和解法一差在哪裡：大多數題目是比較快，少數題目是一樣快但比較好讀。
4. 關掉課文，自己完成 `exercises/` 裡的題目，用測試檢查。
5. 隔一兩天再重寫一次。能不看任何東西寫出來，才算學會。

檢查答案的指令（在專案根目錄執行）：

```bash
bun test leetcode/0001
```

## 什麼時候做哪一題

每一題標著「建議在 Day NN 之後」，表示學完那一天就有足夠的基礎。主線學到哪裡，就做到哪裡。

做完十題之後，可以到 LeetCode 依照題型（陣列、雜湊表、雙指標、堆疊、二分搜尋）各找幾題 Easy 題繼續練。每一種題型做到能在 20 分鐘內寫出來，再往 Medium 前進。

## 題目的版權

LeetCode 的題目敘述受著作權保護。這裡每一題都用自己的話重新描述，範例也是另外設計的。正式的題目敘述、限制條件與線上評測，請點每一題上方的「在 LeetCode 看原題」。
